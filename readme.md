# RotationTiles

Criei uma grelha de 10 × 10 quadrados, em que cada um recebe aleatoriamente uma orientação diferente de curvas, criando vários padrões geométricos e além disso acrescentando uma vertente extra. Quando aproximo o rato de um quadrado, as curvas desse quadrado mudam de orientação e  adicionei a possibilidade de mudar o estilo visual ao clicar no ecrã, as linhas passam de brancas e finas para rosa e mais grossas.
Para fazer isto, utilizei for() para criar e percorrer a grelha, if() e else() para controlar as mudanças e arc() para desenhar as curvas.
A ideia foi pegar num padrão que normalmente é estático e transformá-lo numa composição com a qual podemos interagir.
Foi usada IA para melhor compreenssâo dos comandos if() e else() e um video da criadora PATT VIRA para perceber como funcionaria a construção do código.
